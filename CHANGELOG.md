# Changelog / 変更履歴

This changelog lists formal versions selected for the release-oriented repository. Intermediate experiments remain in the private development repository.

本変更履歴は、公開準備用リポジトリへ選定した正式版のみを記載します。途中の実験版はPrivate開発リポジトリに残します。

## v0.0

### English

- Initial formal Honda Beat power-window controller version.
- Manual right/left UP and DOWN control.
- Simultaneous-switch auto UP/DOWN for both windows.
- ACS712-based current monitoring.
- Endpoint auto-stop using current threshold plus flatness detection.
- Door-open partial down and door-close return up.
- Key-off power hold and EEPROM state retention.

### 日本語

- Honda Beat用パワーウインドウコントローラーの初期正式版。
- 左右ウインドウの手動UP/DOWN制御。
- 左右スイッチ同時操作による両窓オートUP/DOWN。
- ACS712による電流監視。
- 電流閾値＋平坦化判定による終点オートストップ。
- ドア開時パーシャルダウン、ドア閉時復帰UP。
- キーOFF後電源保持およびEEPROM状態保持。
